# LyricWriter

**Минималистичный текстовый редактор для поэзии, песенных текстов и творческой работы.**

LyricWriter — настольный текстовый редактор, созданный для того, чтобы автор мог сосредоточиться на своих текстах. Программа объединяет основные инструменты форматирования с режимом работы без отвлекающих элементов.

## Возможности

- **Режим фокусировки (Focus Mode)** — упрощённая рабочая среда с настраиваемым фоном.
- **Форматирование текста** — выбор шрифта и размера, полужирный, курсив, подчёркивание, стили абзацев и выравнивание.
- **Разметка страницы** — настройка макета документа, интервалов, отступов и списков.
- **Светлая и тёмная темы** — выбор оформления рабочего пространства.
- **Русский и английский интерфейс** — переключение между поддерживаемыми языками.
- **Проверка орфографии** — словари русского и английского языков.
- **Печать и PDF** — печать документов и сохранение в PDF через доступную систему печати.
- **Экспорт документов** — сохранение текста в поддерживаемых форматах.
- **Горячие клавиши** — быстрый доступ к основным операциям редактирования.
- **Работа без интернета** — основные функции редактирования доступны офлайн.

Установщик для Windows доступен на официальной странице релиза GitHub:

**[Скачать LyricWriter 1.0.0](https://github.com/ancient-pholiant/LyricWriter/releases/tag/v1.0.0)**

Скачайте установочный файл из раздела Assets и следуйте инструкциям установщика.

## Установка

1. Скачайте установщик Windows со страницы релиза.
2. Запустите установщик.
3. Выберите параметры установки и предпочтительный язык.
4. Завершите установку и запустите LyricWriter.

Выбранный в установщике язык предназначен для первоначального запуска приложения. Впоследствии язык интерфейса можно изменить в настройках программы.

## Для кого предназначен LyricWriter?

Программа подойдёт:

- поэтам и писателям;
- авторам песен;
- авторам дневников и личных заметок;
- всем, кто предпочитает простой настольный текстовый редактор.
