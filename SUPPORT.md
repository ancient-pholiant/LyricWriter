# Support

For help with LyricWriter, first check the README and the notes for the
release you installed.

When requesting help, include: - LyricWriter version; - Windows
version; - what you expected to happen; - what actually happened; -
reproducible steps and the exact error text.

Do not include passwords, private documents, personal data, or other
confidential material.

This is a free project. Support and response times are not guaranteed.
