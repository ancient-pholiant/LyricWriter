# Security Policy

## Supported versions

Security reports are accepted for the latest published LyricWriter
release. Older versions may not receive fixes.

## Reporting a vulnerability

Please do not publish details of a suspected security vulnerability in a
public issue before the maintainer has had a reasonable opportunity to
assess it.

Use the private contact method listed on the project page, if one is
provided. Include: - the affected LyricWriter version; - your Windows
version; - steps to reproduce the issue; - any relevant error messages
or screenshots.

Do not attach private documents or other sensitive data. There is no
guaranteed response time unless the project page states one.
